# Social-Media-Backend-Rest-API
📱 Social Media Backend REST API
A fully functional backend REST API for a Social Media Platform, developed using Node.js, Express.js, and MongoDB. It supports user registration, authentication, posts, likes, comments, and follows—providing all the essential backend features required to power a social media app.

🚀 Features
🔐 User Authentication & Authorization
Signup/Login using JWT
Password hashing with bcrypt

🧑‍🤝‍🧑 User Profiles
View and update profile
Follow/unfollow other users

📝 Posts
Create, update, delete posts
Like/unlike posts
Add comments

💬 Comments
Add and delete comments on posts

🧭 News Feed
Get posts from followed users

📄 RESTful API Design
Follows REST principles with proper status codes and error handling

🛠️ Tech Stack
Node.js – Server-side JavaScript runtime
Express.js – Web framework for Node
MongoDB – NoSQL database for storing users, posts, comments, etc.
Mongoose – ODM for MongoDB
JWT – Authentication using JSON Web Tokens
bcrypt.js – Secure password hashing
dotenv – Manage environment variables

Postman – API testing (collection included)
